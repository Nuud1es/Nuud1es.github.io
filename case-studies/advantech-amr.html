Case Study — Robotics

Advantech Robotics Internship — Autonomous Mobile Robot

Nagoya, Sep – Nov 2025

Problem

Advantech needed a working AMR demonstrator capable of autonomous navigation for trade show floors — a platform that could reliably move through unpredictable, crowded environments while showcasing Advantech's edge hardware in a live setting.

Approach

  • Built out the robot's navigation stack using ROS2, Nav2, and SLAM Toolbox for mapping and path planning
  • Simulated the robot in NVIDIA Isaac Sim with a holonomic controller for mecanum-wheel drive, iterating in simulation before hardware
  • Integrated LiDAR and RealSense sensors and authored the robot's URDF model
  • Connected an LLM using LangChain, LangGraph and FastAPI so the robot could describe the objects it detected to visitors

Outcome

Demonstrated live at trade shows, navigating autonomously and talking about what it saw in front of attendees.
