Home AI Inference Server

What it is

A self-hosted inference stack running on a home server (AMD Ryzen 7950X, 128GB RAM, AMD 7900 XTX) on Arch Linux — built to explore local LLM hosting without cloud dependency.

Stack

  • ROCm for AMD GPU acceleration + Ollama for model serving
  • Docker Compose for service orchestration
  • n8n for workflow automation on top of the models
  • Tailscale for secure remote access
  • Grafana for monitoring
  • Qdrant for vector storage
  • Piper for local TTS

The interesting part

  • Explored the limits of running llama.cpp across mixed AMD and NVIDIA GPUs, and compared ROCm and CUDA options for scaling inference
  • Recovered the server from an Arch Linux boot failure (a stale fstab entry) by chrooting in from a live USB
This reflects a broader pattern: building interconnected systems rather than isolated scripts — a thread that runs through this project, the Gressingham automation work, and the NorwichVR infrastructure.
